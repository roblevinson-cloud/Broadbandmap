Method

Source. FCC Broadband Data Collection fixed broadband availability, as-of date 30 June 2026, state files for technology code 50 (fiber to the premises), residential and business records.

Brightspeed. FCC provider ID 470022 (Connect Holding II LLC), the only Brightspeed filer in the data. Its fiber footprint is 1,975,566 Broadband Serviceable Locations across 20 states.

Overlap. A Brightspeed passing counts as overbuilt when a rival reports technology 50 at the same location_id in the same filing. Cable, fixed wireless and DSL rivals are excluded — this is fiber-on-fiber only. Rival rows do not sum to the state total: one Brightspeed location can be overbuilt by several rivals, and the state total counts each location once.

Units and identity. Counts are BSLs, not housing units — one location can be a multi-unit building. Rivals are keyed by FCC provider ID rather than brand, so a filer using more than one brand name (Lumos / lumos, Optimum / Lightpath, Cspire / Troy Cablevision) counts once; separate IDs stay separate even where they share a corporate parent.

Built from the FCC BDC public availability files. Counts reflect what providers filed, including any reporting error, and are not audited service records.
