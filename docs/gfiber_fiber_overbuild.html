Method

Source. FCC Broadband Data Collection fixed broadband availability, as-of date 30 June 2026, state files for technology code 50 (fiber to the premises), all record types (residential, business and mixed-use).

Google Fiber. Google Fiber files as FCC provider ID 240041 (Google Fiber Inc.); it is the only Google Fiber filer in the data. Its fiber footprint is 2,075,637 Broadband Serviceable Locations across 16 states.

Overlap. A Google Fiber passing counts as overbuilt when a rival reports technology 50 at the same location_id in the same filing. Cable, fixed wireless and DSL rivals are excluded — this is fiber-on-fiber only. Rival rows do not sum to the state total: one Google Fiber location can be overbuilt by several rivals, and the state total counts each location once.

Units and identity. Counts are BSLs, not housing units — one location can be a multi-unit building. Rivals are keyed by FCC provider ID rather than brand, so a filer using more than one brand name counts once — for example AT&T / Quantum Fiber; CenturyLink / Quantum Fiber; Optimum / Lightpath; separate IDs stay separate even where they share a corporate parent.

Built from the FCC BDC public availability files. Counts reflect what providers filed, including any reporting error, and are not audited service records.
