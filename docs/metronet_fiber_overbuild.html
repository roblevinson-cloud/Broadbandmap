Method

Source. FCC Broadband Data Collection fixed broadband availability, as-of date 31 December 2025, state files for technology code 50 (fiber to the premises), all record types (residential, business and mixed-use).

Metronet. Metronet files as FCC provider ID 131081 (Metronet Holdings, incl. Vexus Fiber; a T-Mobile / KKR joint venture since July 2025); it is the only Metronet filer in the data. Its fiber footprint is 2,612,686 Broadband Serviceable Locations across 21 states.

Overlap. A Metronet passing counts as overbuilt when a rival reports technology 50 at the same location_id in the same filing. Cable, fixed wireless and DSL rivals are excluded — this is fiber-on-fiber only. Rival rows do not sum to the state total: one Metronet location can be overbuilt by several rivals, and the state total counts each location once.

Units and identity. Counts are BSLs, not housing units — one location can be a multi-unit building. Rivals are keyed by FCC provider ID rather than brand, so a filer using more than one brand name counts once — for example Geneseo Communications Services Inc / Geneseo Telephone Company; Nuvera Communications / Scott Rice Tel. Co.; Long Lines Metro, LLC / Northwest Iowa Telephone Co Inc; separate IDs stay separate even where they share a corporate parent.

Caveats. US Internet (Minneapolis and Winnebago County, Wisconsin; about 101,000 fiber locations filed under ID 400137 in the June 2025 vintage), which Metronet acquired on 2 September 2025, does not appear in the December 2025 filing under any ID. This footprint therefore understates Metronet's post-acquisition network by roughly 100,000 locations, and the Minneapolis market is effectively absent (the ID has only 3,901 Hennepin County locations).

Vexus Fiber (Louisiana, New Mexico, Texas) is filed under the same ID and included. The Connecticut (3) and Mississippi (2) rows are stray records; Metronet's own count is 19 states. Residential service sold under the T-Mobile Fiber brand since the July 2025 joint venture is still filed under this ID.

Built from the FCC BDC public availability files. Counts reflect what providers filed, including any reporting error, and are not audited service records.
